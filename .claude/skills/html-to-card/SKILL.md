# html-to-card：一頁式 HTML → PNG 教學圖卡

## 開始前先讀

- `style/style-guide.md`
- `style/xingbingle.svg`（星冰樂角色設定）
- `prompts/00-character-sheet.md`（角色設定圖 prompt，只需做一次）

## 路線 A：程式截圖（版面最穩定）

```bash
python scripts/render_png.py html/NN-xxx.html
```

輸出 `png/NN-xxx.png`（2160×2700，2 倍解析度）。文字 100% 正確，適合當正式教材。

## 路線 B：AI 重新繪製（插畫感最強）

AI 生圖最大的問題是「每張長得不一樣」，所以要固定三樣東西：

1. **固定角色**：第一次先用 `prompts/00-character-sheet.md` 產生星冰樂角色設定圖，存成 `style/character-sheet.png`。之後每張卡都把這張圖一起上傳。
2. **固定版面**：把路線 A 的 PNG 一起上傳當「版面草稿」，AI 只負責重畫風格，不負責排版。
3. **固定 prompt**：每張卡的 prompt 都由下方模板產生，只替換 `{...}` 的部分。

### prompt 模板

```text
請參考我上傳的兩張圖：
圖 1 是吉祥物「星冰樂」的角色設定圖，圖 2 是這張教學圖卡的版面草稿。

請把圖 2 重新繪製成乾淨、留白多的直式教學圖卡（4:5），要求：
- 版面、區塊順序、所有中文與英文文字都和圖 2 完全相同，不可增減或改字
- 奶油黃底 #FFF0CF，不要格線、紙膠帶、粗黑框或花俏裝飾
- 文字深藍 #202B49；一句話定義用天空藍底塊 #8FD3F4；研究小抄用橘色 #FFB94A；紅色 #F2463D 只當點綴
- 星冰樂必須和圖 1 一樣：銀灰色英國短毛貓、白色胸口與腳掌、淡虎斑、黃綠色眼睛、奶茶色項圈掛紅色御守
- 星冰樂用正常比例的扁平插畫，不要 Q 版、不要大頭、不要 3D、不要寫實照片
- 本張的星冰樂動作：{pose}
- 可以在留白處加 1 個和主題有關的極簡線條小圖示：{doodles}
```

### 每張卡的變數

在 `prompts/NN-xxx.md` 寫好 `{pose}` 和 `{doodles}`，再把整段 prompt 組好存檔，方便使用者直接複製。

### 產生後的檢查（很重要）

AI 生圖常把中文字畫錯，產生後一定要逐字對照 HTML：
- [ ] 標題、數字、作者年份沒有錯字
- [ ] 星冰樂的毛色、眼睛顏色、紅色御守有沒有跑掉，有沒有變成 Q 版
- [ ] 有錯就在同一個對話中指出「第幾區的哪幾個字錯了」請它修，修不好就改用路線 A 的版本

存成 `png/ai/NN-xxx.png`。
