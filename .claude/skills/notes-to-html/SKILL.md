# notes-to-html：內容筆記 → 一頁式 HTML

## 開始前先讀

1. `style/style-guide.md`（顏色、字體、版面、星冰樂設定）
2. 任一份既有筆記，例如 `notes/01-injury-prediction.md`，照它的格式寫

## 步驟

### 1. 寫筆記 `notes/NN-英文短名.md`

固定格式（標題、順序都不能改，腳本靠它們解析）：

```markdown
---
id: "05"
title: 中文標題（8 字內）
en: English Title
sources: 作者 年份、作者 年份
---

## 一句話定義
（40–50 字）

## 三個重點
1. **小標**：說明（40 字內）。[作者 年份]
2. **小標**：說明。[作者 年份]
3. **小標**：說明。[作者 年份]

## 研究小抄
- 一個具體數字或發現 [作者 年份]
- 第二個 [作者 年份]

## 星冰樂小提醒
（口語、像學姊提醒，35 字內）
```

### 2. 內容規則

- 內容只能來自使用者的 LLM Wiki（`ai-sport-wiki/wiki/`），不要自己補數字。
- 每個數字都附 `[作者 年份]`。
- 論文寫 may／suggest，中文就寫「可能」，不要寫成定論。
- Wiki 裡標 ⚠ 的分歧，挑一個寫進「星冰樂小提醒」或「研究小抄」，提醒讀者別只看單一說法。
- 全卡內文 220 字以內。

### 3. 轉成 HTML

```bash
python scripts/build_html.py notes/NN-xxx.md
```

輸出到 `html/NN-xxx.html`。版型與樣式全部來自 `style/card.css`，**不要在個別 HTML 裡改樣式**，要改就改 css，所有卡片一起變。

### 4. 自我檢查

用瀏覽器開 HTML（1080×1350），確認：
- [ ] 三個重點都有出現、沒有文字溢出框外
- [ ] 星冰樂沒有被頁尾蓋住，上方小提醒沒有超過 4 行
- [ ] 頁尾來源和筆記的 sources 一致

檢查通過後交給 `html-to-card` skill。
