# 風格指南：星冰樂運動科學手帳風

所有圖卡都必須遵守這份指南。兩個 skill（notes-to-html、html-to-card）都會先讀這份檔案。

## 1. 整體感覺

- 像一本「運動科學學習手帳」：米白紙張、方格底紋、紙膠帶、便利貼、手寫感標題。
- 可愛但不幼稚，內容要經得起研究生閱讀。
- 每張圖卡只講**一個概念**，讀者 30 秒內要看懂重點。

## 2. 版面規格

| 項目 | 規格 |
|---|---|
| 尺寸 | 1080 × 1350 px（4:5 直式，適合 IG／簡報插頁） |
| 外框 | 圓角 28px，紙張外留 36px 邊 |
| 區塊數 | 固定 4 區：①標題列 ②一句話定義 ③三個重點 ④研究小抄＋提醒 |
| 頁尾 | 左：系列名「星冰樂的運動科學手帳」＋編號；右：資料來源 |

## 3. 色票

| 用途 | 名稱 | 色碼 |
|---|---|---|
| 紙張底色 | 奶茶米 | `#FBF5EA` |
| 方格線 | 淡卡其 | `#EDE3D1` |
| 主文字 | 深灰藍 | `#3B4559` |
| 主色（星冰樂毛色） | 灰藍 | `#8496AD` |
| 強調色（星冰樂眼睛） | 銅橘 | `#E8973F` |
| 輔助色 1（頭帶） | 薄荷綠 | `#7CC6B5` |
| 輔助色 2（紙膠帶） | 蜜桃粉 | `#F4B6B0` |
| 便利貼 | 奶油黃 | `#FFE9A8` |

規則：一張卡最多用 1 個強調色區塊（銅橘），其餘用主色與輔助色。

## 4. 字體

- 標題：`Noto Sans TC` Black（900），36–60px
- 內文：`Noto Sans TC` Medium（500），24–28px，行高 1.55
- 英文術語與數字：保留原文（例如 ACWR、ROC AUC 0.80），不要翻成中文

## 5. 吉祥物：星冰樂

角色設定圖見 `style/xingbingle.svg`。

- 英國短毛貓，**灰藍色**毛、**銅橘色大圓眼**、寬圓臉、圓滾肉頰、小耳朵
- 招牌配件：**薄荷綠運動頭帶**（白色虛線車縫），每張圖都要戴
- 每張卡出現 1 次，位置在右下或左下，搭配一個和主題相關的小道具（放大鏡、碼錶、啞鈴、筆記板等）
- 星冰樂會用對話框說一句「小提醒」，語氣口語、像學姊提醒學弟妹

## 6. 文字規則

- 數字一定要附來源，格式：`[作者 年份]`
- 不誇大：論文說「may」就寫「可能」
- 一張卡內文總字數控制在 220 字以內
