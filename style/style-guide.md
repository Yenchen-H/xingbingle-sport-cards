# 風格指南：星冰樂的運動科學手帳（乾淨版面）

所有圖卡都必須遵守這份指南。兩個 skill（notes-to-html、html-to-card）都會先讀這份檔案。

## 1. 整體感覺

- 乾淨、留白多、像一頁精緻的講義或雜誌內頁。
- 不用格線底紋、紙膠帶、粗黑框、Q 版角色。
- 每張圖卡只講**一個概念**，讀者 30 秒內要看懂重點。

## 2. 版面規格

| 項目 | 規格 |
|---|---|
| 尺寸 | 1080 × 1350 px（4:5 直式） |
| 邊界 | 左右 88px、上 84px，大量留白 |
| 區塊 | 固定 4 區：①標題 ②一句話定義（淺灰底塊） ③三個重點（01／02／03 編號，不加框） ④研究小抄＋星冰樂 |
| 頁尾 | 細線分隔；左：系列名＋編號；右：資料來源 |

## 3. 色票

| 用途 | 名稱 | 色碼 |
|---|---|---|
| 底色 | 米白 | `#FAF9F6` |
| 主文字 | 墨黑 | `#24272E` |
| 次要文字 | 霧灰 | `#7B808B` |
| 強調色（星冰樂的御守） | 御守紅 | `#C8423B` |
| 輔助色（星冰樂毛色） | 銀灰 | `#B3B7BF` |
| 定義底塊 | 淺米灰 | `#F0EEE9` |

規則：紅色只用在系列名、編號、小標記與星冰樂的一句話，不大面積使用。

## 4. 字體

- 全部使用 `Noto Sans TC`：標題 Black（900）74px；小標 900、29px；內文 500、23px，行高 1.6
- 英文術語與數字保留原文（ACWR、ROC AUC 0.80）

## 5. 吉祥物：星冰樂

角色設定見 `style/xingbingle.svg`，依真實照片繪製。

- 銀灰色英國短毛貓，**正常比例、不畫 Q 版**，扁平插畫、不加外框線
- 白色胸口、口鼻與腳掌，身上與腳有淡淡虎斑，額頭有 M 字紋
- 黃綠色眼睛、粉紅鼻子
- 招牌配件：**奶茶色項圈＋紅色御守**，每張圖都要有
- 固定在右下角正面坐姿，上方用一條紅色直線引出一句「小提醒」，語氣口語

## 6. 文字規則

- 數字一定要附來源，格式：`[作者 年份]`
- 不誇大：論文說「may」就寫「可能」
- 一張卡內文總字數控制在 220 字以內
